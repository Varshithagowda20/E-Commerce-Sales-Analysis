# 📊 E-Commerce Sales Analysis

## About the Project

I completed this project to practice the end-to-end data analysis process using Excel, MySQL, and Power BI. Starting with a raw sales dataset, I cleaned the data, analyzed it using SQL, and created an interactive dashboard in Power BI to understand sales performance and business trends.

## What I Did

### 📊 Microsoft Excel
- Cleaned and organized the sales dataset
- Removed duplicate records and checked for missing values
- Created Pivot Tables and Pivot Charts
- Built an interactive Excel dashboard

### 🗄️ MySQL
- Imported the cleaned dataset into MySQL
- Wrote SQL queries to analyze sales, profit, customers, and regions
- Used aggregate functions, GROUP BY, HAVING, and subqueries to answer business questions

### 📈 Power BI
- Built an interactive dashboard using Power BI
- Created DAX measures for key performance indicators (KPIs)
- Added slicers for easy filtering
- Designed charts to present business insights clearly
